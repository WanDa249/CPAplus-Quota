# CPAplus 额度助手

<img src="assets/icon.png" width="72" alt="额度助手图标">

Windows 11 任务栏上的轻量 Codex 额度显示工具。查看独立账号的五小时／周额度、重置时间和最近成功更新时间；支持托盘详情、多个绑定账号、本地备注及 Codex 启停联动。

**[下载 v0.1.0-beta](https://github.com/WanDa249/CPAplus-Quota/releases/tag/v0.1.0-beta)** · Windows x64 · 单 EXE · 免安装

这是独立的非官方客户端，不隶属于 OpenAI 或 Microsoft。需要支持用户额度接口的 CPA 服务和自己的 CPA API Key；不提供账号、注册服务或公共服务器。

## 三步开始

1. 从 Releases 下载 **`CPAplusQuota.exe`**，保存到固定目录。双击即可运行，不用安装、解压、安装字体或准备 Fonts 文件夹；无需管理员权限。支持 Windows 11 x64，依赖系统 .NET Framework 4.8 或兼容更新，不需要 .NET SDK、Python、Node.js。
2. 点击系统托盘中的额度卡片图标，进入「设置 → 更换密钥」。填写服务管理员提供的 **HTTPS 服务地址** 和自己的 **CPA API Key**，点击「保存并连接」。地址只允许站点根地址，例如 `https://quota.example.invalid`；这个示例不能用于实际连接。不要填管理口令、OAuth token 或 OpenAI API Key。
3. 打开 Windows Codex 桌面应用后，任务栏出现 `5h 62% · 周 46%` 一行额度。点击查看详情；展开「还有 N 个账号」可切换主显示账号，设置中可添加本地备注。

**源码和 EXE 不内置任何真实服务地址、账号或密钥。** 服务地址由用户本地配置，密钥进入 Windows Credential Manager。请只填写自己信任的服务，API Key 会发送给你配置的 HTTPS 站点。

## 日常使用

- 默认检测到 Codex 图形应用后显示并每15秒读取服务器缓存；Codex 完全退出后隐藏并暂停读取，助手在后台等待。CLI／后台辅助进程不会单独触发显示。
- 点击「刷新」请求当前主显示账号更新；实际供应商读取、去重、冷却与退避由服务端控制。「额度更新于」表示真实上游成功时间，不是客户端读缓存时间。旧缓存、失败、冻结和停用分别标记，不把旧结果冒充实时。
- 多个账号独立显示，额度不相加。高于50%为绿，21%–50%为黄，20%及以下为红；颜色不保证账号一定可调用。
- 同一账号的任务栏额度数字变化时轻微淡入，约200毫秒结束；数字未变、恢复显示或切换账号时不播放，遵循Windows动画设置。界面使用简洁查询提示，过期和失败状态仍明确显示。
- 查询中和完成后的弹窗及按钮尺寸保持不变；展开账号、收起和切换页面时使用约180毫秒的平滑尺寸过渡，仅在助手内启用，不修改Windows动画设置。
- 设置或托盘「显示时机」可选择 Codex 运行时、仅 Codex 前台、始终显示、Codex 未最小化时显示、隐藏任务栏额度，选择会保留到下次启动。未最小化模式只在所有 Codex 窗口都最小化时收起，恢复任意窗口后显示；切到其他应用不会单独触发收起。隐藏只关闭任务栏额度条，托盘及详情仍可使用。主屏任务栏空间不足或全屏时仍会收起额度条。
- 关闭弹窗只收起页面；右键托盘「退出」结束助手。设置中开启「随 Windows 静默启动」即可登录后常驻，不需要创建联合启动快捷方式。
- 更换服务地址会清空旧服务的显示状态并切换独立凭据、备注作用域，不把旧密钥自动发给新站点。

## 升级与清理

从托盘退出，下载新版 EXE 并核对 SHA-256，然后覆盖原目录同名文件，再双击。密钥、服务地址及备注不保存在 EXE 旁，同目录覆盖升级会保留；若移动 EXE，重新开启一次静默启动来更新路径。

不再使用时先关闭静默启动，从托盘退出并删除 EXE。个人配置可在当前用户的 Windows 凭据管理器及 `%LOCALAPPDATA%\CPAplusQuota` 自行清理；服务地址在 `HKCU\Software\CPAplusQuota`。不要把这些个人配置加入公开仓库或故障报告。

字体及完整许可内嵌于 EXE，运行时自动释放到本地用户目录供原有 WPF/GDI 渲染器使用，不安装系统字体。

## 常见问题

**没有额度条？** 可先从托盘找额度卡片图标。确认运行的是 Windows Codex 图形应用；首版针对官方打包版应用及 Windows 11 主屏底部任务栏验证，未承诺第三方任务栏、所有多屏或竖向布局。拥挤或全屏时会收起，避免挡住其他按钮。

**密钥不可用或账号缺失？** 请联系服务管理员核对绑定。客户端只能查看当前密钥授权的账号，不能扩大权限或管理账号。服务地址必须提供兼容接口，普通网页地址不能直接使用。

**时间或额度没变？** 客户端每15秒重读缓存不会强迫供应商每15秒更新。新鲜度由服务端和供应商决定，限流或失败会延长；检查最近成功时间及错误标记。百分比四舍五入后可能数值不变。

**连接不上？** 确认 HTTPS 地址、证书和网络。客户端不跟随跨站重定向、不忽略证书错误，也不使用系统代理。

**Windows 提示发布者未知？** 首版未签名，可能出现 SmartScreen 提示。只从本仓库 Release 下载并核对校验和；不要关闭 Defender 或绕过单位安全策略。校验和检查完整性，不能替代发布者签名。

**如何核对下载？** 下载同一 Release 的 `SHA256SUMS.txt`，在 PowerShell 执行 `Get-FileHash .\CPAplusQuota.exe -Algorithm SHA256`，与文件中的哈希逐字比较。

在 Windows 11 x64 克隆仓库后，从 PowerShell 执行 `./build.ps1`，输出 `bin/CPAplusQuota.exe`。使用系统 .NET Framework C# 编译器和 WPF/WinForms，不需要 NuGet 或独立 SDK；字体和图标构建输入都在本仓库中。源码结构为 `src/`、`assets/`、`licenses/` 与 `build.ps1`。

所需服务端接口为 `GET /v1/me/quotas` 和可选 `POST /v1/me/quotas/refresh`，都使用 Bearer 头，刷新用 `X-Quota-Account` 指定返回数据中的不透明账号别名。接口应由服务端按密钥绑定隔离并过滤敏感字段；本仓库不提供服务端实现。
